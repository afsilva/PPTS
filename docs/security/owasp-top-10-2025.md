## Local-only constraints

The committed Keycloak realm deliberately uses HTTP and `sslRequired=none` because both browser-facing ports bind to loopback. The application rejects non-loopback HTTP origins. This configuration must never be exposed to a LAN or reused as production identity configuration.

Synthetic administrator and employee accounts contain no committed passwords. Credentials are generated into a protected external runtime file. The business seed creates only a synthetic client, status, project, and work-code catalog; authenticated users are provisioned from validated OIDC identity and membership is never derived from a mutable username.

Current day/week totals and labels use UTC. Organization timezone, correction approval, reporting, and retention rules require business decisions before production reporting work.

## Required release gates

Before production approval, complete the remaining work above, satisfy OWASP ASVS 5.0 Level 2 evidence requirements, test every authorization-matrix capability in both allowed and denied cases, run DAST and an independent security review, and rehearse backup/restore and rollback procedures.
