## Local-only constraints

The committed Keycloak realm deliberately uses HTTP and `sslRequired=none` because both browser-facing ports bind to loopback. The application rejects non-loopback HTTP origins. This configuration must never be exposed to a LAN or reused as production identity configuration.

Synthetic administrator, manager, and employee accounts contain no committed passwords. Credentials are generated into a protected external runtime file. The business seed creates only a synthetic client, status, project, and work-code catalog; authenticated users are provisioned from validated OIDC identity and membership is never derived from a mutable username.

Dashboard day/Monday-week totals and monthly HTML/CSV reports use the validated `ORGANIZATION_TIME_ZONE` IANA setting with DST-aware local boundaries and clipping. UTC is the local default; the production business zone, export retention, and audit retention still require owner approval. Time correction itself requires no manager approval: verified legacy behavior is immediate own-only correction, and modern ownership checks prevent role-based cross-user edits. The correction editor preserves seconds/milliseconds, rejects overlap/future/overlong intervals, paginates bounded queries, and does not version or audit unchanged submissions.

Clock-in, switch, clock-out, available, and off-duty commands require a UUID submission key generated in the rendered form. The server scopes receipts to the authenticated actor, fingerprints normalized action/payload data without retaining submitted status text, and commits the receipt with the business state and one success audit in the same Serializable transaction. Exact retries return the original result; reuse for another action or payload fails closed. Receipts expire after 24 hours and must be purged with the documented maintenance command.

## Required release gates

Before production approval, complete the remaining work above, satisfy OWASP ASVS 5.0 Level 2 evidence requirements, finish allowed/denied evidence for authorization capabilities outside the shipped time/project/report/document slice, run DAST and an independent security review, and rehearse backup/restore and rollback procedures.
