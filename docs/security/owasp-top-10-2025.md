# OWASP Top 10:2025 status

**Reviewed:** 2026-11-07  
**Scope:** local/pre-release authentication foundation  
**Release decision:** suitable for loopback-only development; **not approved for production**

This document records the current control posture against the official [OWASP Top 10:2025](https://top10.owasp.org/2025/0x00_2025-Introduction/). It is not a certification or a substitute for ASVS verification, penetration testing, or a production threat assessment.

## Local-only constraints

The committed Keycloak realm deliberately uses HTTP and `sslRequired=none` because both browser-facing ports bind to loopback. The application rejects non-loopback HTTP origins. This configuration must never be exposed to a LAN or reused as production identity configuration.

Synthetic administrator and employee accounts contain no committed passwords. Credentials are generated into a protected external runtime file and are reset/reconciled only for the local realm.

## Required release gates

Before production approval, complete the remaining work above, satisfy OWASP ASVS 5.0 Level 2 evidence requirements, test every authorization-matrix capability in both allowed and denied cases, run DAST and an independent security review, and rehearse backup/restore and rollback procedures.
